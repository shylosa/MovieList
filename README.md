# 🍿 MovieList - Менеджер локальної медіатеки

**MovieList** — це потужний Python-скрипт, який перетворює хаотичну папку з відеофайлами на красивий, структурований локальний кінотеатр та хмарну базу даних. 

Система автоматично сканує файли, розпізнає назви, завантажує постери й описи з бази TMDB, а для найскладніших випадків (трансліт, піратські назви релізів) використовує штучний інтелект Google Gemini.

## ✨ Головні фішки
* **🧠 Гібридне розпізнавання:** Класичний пошук через TMDB + бекап-парсинг через ШІ (Gemini) для найскладніших назв файлів.
* **🇺🇦 UA локалізація:** Пріоритет українських назв, описів та жанрів. Якщо перекладу немає — ШІ генерує його на льоту.
* **✏️ Вбудований редактор:** Зручна панель у лаунчері для швидкого ручного виправлення нерозпізнаних файлів (за ID, роком або точним посиланням).
* **🎨 Блискавична локальна HTML-вітрина:** Автоматична генерація `index.html` з адаптивною сіткою, миттєвим пошуком та сортуванням. Повністю автономна (працює без інтернету та локального сервера).
* **☁️ Хмарна синхронізація:** Надійний експорт (з вбудованим захистом від лімітів API) усієї колекції в Google Sheets для зручного доступу з телефону будь-де.
* **💾 Розумний кеш та безпека:** Локальна база SQLite (`movies.db`) береже ліміти API, постери зберігаються офлайн із захистом від вразливостей файлової системи, а HTML-генератор захищений від XSS.

## 🛠️ Вимоги до системи
Перед початком переконайтеся, що у вас встановлено:
* **Python 3.13** або новіше.
* Отримано ключі доступу (API Keys):
  * [TMDB API Key](https://www.themoviedb.org/settings/api) (Для пошуку фільмів та постерів).
  * [Google Gemini API Key](https://aistudio.google.com/) (Для парсингу складних назв).
  * Файл `credentials.json` від Google Cloud Console (Для доступу до Google Sheets).

## 🚀 Встановлення та налаштування (Швидкий старт)

**1. Клонуйте репозиторій (або завантажте папку):**
```bash
git clone [https://github.com/ВАШ_ЮЗЕРНЕЙМ/movielist.git](https://github.com/ВАШ_ЮЗЕРНЕЙМ/movielist.git)
cd movielist
```
**2. Створіть та активуйте віртуальне середовище:**
```bash
python -m venv venv
venv\Scripts\activate
```
**3. Встановіть залежності:**
```bash
pip install -r requirements.txt
```
**4. Налаштуйте змінні оточення:**
Скопіюйте файл .env.example і перейменуйте його на .env. Відкрийте його і впишіть свої ключі та шляхи:
```dotenv
TMDB_API_KEY=твій_ключ_tmdb
GEMINI_API_KEY=твій_ключ_gemini
MEDIA_FOLDER_PATH=D:\Films
EXCLUDE_FOLDERS=System Volume Information, $RECYCLE.BIN
GOOGLE_SHEET_WORKSHEET_NAME=movies
```
**5. Підключіть Google Sheets:**
Покладіть ваш файл `credentials.json` у кореневу папку проєкту.

**6. Заглушка для постерів:**
Створіть папку assets у корені проєкту та покладіть туди зображення no-poster.jpg — воно буде використовуватись для фільмів, у яких відсутній офіційний постер.

🎮 Керування та використання
Проєкт оснащений швидкою та стильною графічною панеллю керування (CustomTkinter), що позбавляє необхідності працювати з консоллю вручну. Для запуску використовуйте універсальний файл MovieList.bat або запустіть launcher.pyw.

Головне меню (Дії):

🔍 Оновити базу — ініціює розумне сканування медіатеки. Скрипт знайде нові файли, завантажить постери та залучить Gemini AI для складних назв.

☁️ Синхронізувати — безпечно відправляє актуальні дані з локальної бази у хмару (Google Sheets).

📊 Відкрити таблицю — швидкий перехід до вашої Google Таблиці у браузері.

🎬 Відкрити вітрину — генерує свіжий index.html та відкриває ваш персональний офлайн-кінокаталог.

Інструменти:

✏️ Редактор — потужна таблиця для ручного коригування. Якщо ШІ не впорався, ви можете ввести точний рік або ID фільму, вибрати файли галочками і натиснути "Виправити вибрані".

📁 Папка з логами — швидкий доступ до історії розпізнавання.

Особливості інтерфейсу:

Dark Mode: Дизайн для комфортної роботи.

Live Log: Усі події відображаються у реальному часі у вбудованому терміналі (stdout).

💡 Порада: У веб-каталозі використовуйте перемикач "Сітка / Список" у верхньому меню. Режим списку ідеально підходить для швидкого перегляду великих колекцій з акцентом на сюжети та назви файлів. А клік по постеру відкриє його у повному розмірі!


**📁 Структура проєкту<br>**

`launcher.pyw` — Графічний інтерфейс користувача (GUI) та диспетчер завдань.

`main.py` — Головний контролер логіки (сканування -> TMDB -> Gemini -> Збереження).

`scanner.py` — Швидкий обхід локальної файлової системи.

`fetcher.py` — Взаємодія з API TMDB (мульти-пошук, завантаження зображень, SRP-архітектура).

`ai_parser.py` — Звернення до Google Gemini для "лікування" поганих назв.

`database.py` — Робота з локальною базою SQLite (movies.db).

`build_html.py` — Високопродуктивний генератор SPA-вітрини index.html із вбудованим JS-пошуком та XSS-захистом.

`sheets.py` — Синхронізація з Google Sheets (з автоматичним ретраєм при лімітах API).
