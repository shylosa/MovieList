# 🍿 MovieList - Менеджер локальної медіатеки

**MovieList** — це потужний Python-скрипт, який перетворює хаотичну папку з відеофайлами на красивий, структурований локальний кінотеатр та хмарну базу даних. 

Система автоматично сканує файли, розпізнає назви, завантажує постери й описи з бази TMDB, а для найскладніших випадків (трансліт, піратські назви релізів) використовує штучний інтелект Google Gemini.

## ✨ Головні фішки
* **🧠 Гібридне розпізнавання.** Класичний пошук через TMDB + бекап-парсинг через ШІ (Gemini) для складних назв файлів.
* **UA локалізація.** Пріоритет українських назв, описів та жанрів. Якщо перекладу немає — ШІ генерує його на льоту.
* **🎨 Локальна HTML-вітрина:** Автоматична генерація `index.html` з адаптивною сіткою, миттєвим пошуком та сортуванням (без необхідності піднімати веб-сервер).
* **☁️ Хмарна синхронізація:** Експорт усієї колекції в Google Sheets для зручного доступу з телефону будь-де.
* **⚡ Розумний кеш:** Локальна база SQLite (`movies.db`) зберігає дані, щоб не "смикати" API при кожному запуску, та зберігає постери офлайн.
* **⚡ Логування:** Система логує процес розпізнавання назв фільмів.

## 🛠️ Вимоги до системи
Перед початком переконайтеся, що у вас встановлено:
* **Python 3.10** або новіше.
* Отримано ключі доступу (API Keys):
  * [TMDB API Key](https://www.themoviedb.org/settings/api) (Для пошуку фільмів та постерів).
  * [Google Gemini API Key](https://aistudio.google.com/) (Для парсингу складних назв).
  * Файл `credentials.json` від Google Cloud Console (Для доступу до Google Sheets).

## 🚀 Встановлення та налаштування (Швидкий старт)

**1. Клонуйте репозиторій (або завантажте папку):**
```bash
git clone [https://github.com/ВАШ_ЮЗЕРНЕЙМ/movielist.git](https://github.com/ВАШ_ЮЗЕРНЕЙМ/movielist.git)
cd movielist
```
**2. Створіть та активуйте віртуальне середовище:**
```bash
python -m venv venv
venv\Scripts\activate
```
**3. Встановіть залежності:**
```bash
pip install -r requirements.txt
```
**4. Налаштуйте змінні оточення:**
Скопіюйте файл .env.example і перейменуйте його на .env. Відкрийте його і впишіть свої ключі та шляхи:
```dotenv
TMDB_API_KEY=твій_ключ_tmdb
GEMINI_API_KEY=твій_ключ_gemini
MEDIA_FOLDER_PATH=D:\Films
EXCLUDE_FOLDERS=System Volume Information, $RECYCLE.BIN
GOOGLE_SHEET_WORKSHEET_NAME=movies
```
**5. Підключіть Google Sheets:**
Покладіть ваш файл `credentials.json` у кореневу папку проєкту.


🎮 Керування та використання
Проєкт оснащений зручною графічною панеллю керування, що позбавляє необхідності працювати з консоллю вручну. Для запуску використовуйте універсальний файл `MovieList.bat`.

**Графічний лаунчер (GUI)**

Після запуску відкриється вікно з інтуїтивним керуванням:

* 🔍 Оновити базу — ініціює повне сканування медіатеки. Скрипт знайде нові файли, завантажить постери та за потреби звернеться до Gemini AI для розпізнавання складних назв.

* ☁️ Синхронізувати — миттєво відправляє актуальні дані з вашої локальної бази прямо у хмару (Google Sheets).

* 🎬 Відкрити вітрину — генерує свіжий index.html та відкриває ваш персональний кінокаталог у браузері.

**Особливості інтерфейсу:**

* Dark Mode: Інтерфейс лаунчера повністю адаптований під темну тему Windows для комфортної роботи.

* Live Log: Усі події (статус завантаження, відповіді ШІ, прогрес сканування) відображаються у реальному часі у вбудованому полі логів.

* Favicon Support: Ваша веб-вітрина має фірмову іконку вкладки для зручного пошуку серед інших вікон.

💡 Порада: У веб-каталозі використовуйте перемикач "Сітка / Список" у верхньому меню. Режим списку ідеально підходить для швидкого перегляду великих колекцій з акцентом на сюжети та назви файлів.


**📁 Структура проєкту<br>**

`main.py` — Головний контролер логіки (сканування -> TMDB -> Gemini -> Збереження).

`scanner.py` — Обхід локальної файлової системи.

`fetcher.py` — Взаємодія з API TMDB (мульти-пошук фільмів/серіалів та завантаження картинок).

`ai_parser.py` — Звернення до Google Gemini для "лікування" поганих назв.

`database.py` — Робота з локальною базою SQLite (movies.db).

`build_html.py` — Генерація SPA-вітрини index.html із вбудованим JS-пошуком.

`sheets.py` — Синхронізація з Google Sheets.

`launcher.pyw` - Лаунчер проєкта.
